Make it yours, take it anywhere

Click Edit keys to change any button's label, icon and action right in the app. Use Export settings to save everything to one file. Import settings loads it on any PC, backing up what was there first. Moving computers takes seconds.

Set up in a minute

No installer, no sign-in.

Download

Grab Deck.zip and extract deck.exe anywhere, like Documents\Deck.

Run it

Double-click. A tray icon appears and the deck opens in its own window. If Windows warns about an unsigned app, choose More info → Run anyway.

Make it yours

Use the gear menu → Edit keys to set up your own buttons, and tick Start with Windows in the tray menu.
