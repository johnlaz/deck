LazDeck

A Stream Deck-style button widget for your Windows desktop. One small exe, no installer, no account.

Download LazDeck.exe All files

Install

  1. Download LazDeck.exe and put it anywhere (for example Documents\LazDeck).
  2. Double-click it. A tray icon appears and the deck opens in its own window.
  3. Optional: tray menu → Start with Windows.

Windows may show a SmartScreen notice for an unsigned app: choose More info → Run anyway.

What it does

  • 15-button pages: launch apps and sites, send hotkeys, paste text templates, run timers, mic mute.
  • Outlook and Spotify pages appear automatically when those apps are in front.
  • Optional Home Assistant buttons.

Back up or move your setup

Open the gear button in the dashboard: Export settings saves your layout, custom icons and templates to one lazdeck-settings.json. Import settings loads it on any PC (current files are backed up first).

Install as an app (optional)

The dashboard runs at http://127.0.0.1:8788. In Edge, use ··· → Apps → Install this site as an app if you want a taskbar-pinnable window.
